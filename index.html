Roblox Studio Plugin
Built for
your workflow.

The UIForge Studio plugin connects to your account and listens for new generations. Import any UI directly into your game hierarchy — no manual work.

  1. 1
    Install the plugin from the Roblox Creator Store — it's free.
  2. 2
    Connect your account using your UIForge plugin token from Settings.
  3. 3
    Generate UI on the website, refine in the visual preview.
  4. 4
    Click Import in the plugin — UI appears in StarterGui instantly.
